# Furniture Sales Analytics Dashboard 📊

An interactive **Data Analysis & Sales Analytics Dashboard** built from furniture sales data.

The project focuses on transforming raw sales records into an interactive dashboard that makes it easier to explore sales performance, products, customers, regions, and delivery operations.

---

## 🚀 Project Overview

For this project, I worked on the **data cleaning and preparation**, then used **AI-assisted development** to build an interactive dashboard in **HTML**.

The goal was to turn the data into a practical analytical tool rather than just a collection of charts.

### What the Dashboard Covers

- 💰 Sales performance
- 📦 Order volume
- 🛋️ Product performance
- 🚚 Delivery performance
- ⏱️ Delivery delays
- 👥 Customer analysis
- 📍 Regional analysis
- 💳 Payment methods
- 🏪 Sales platforms
- 📋 Detailed order-level reporting

---

## 📌 Key Features

### Interactive Filters

The dashboard supports filtering by:

- Date range
- Sales platform
- Category
- Product type
- Model / product name
- Size
- Color
- Fabric color
- Payment method
- Order status
- Area
- Delivery owner

### 📊 KPIs

The overview provides key metrics including:

- Total Sales
- Number of Orders
- Average Selling Price
- On-Time Delivery Rate
- Cancellation Rate

### 🛋️ Product Analysis

Explore product performance and identify:

- Top-performing products
- Best-selling products
- Lower-performing products
- Sales contribution by product

### 🚚 Delivery Analysis

The delivery section includes:

- Planned vs. actual delivery dates
- Delivery performance
- Delay distribution
- Delivery owner analysis
- Delivery summary

### 👥 Customer & Regional Analysis

Analyze:

- Top customers
- Orders by region
- Sales value by area
- Address-level order concentration
- Customer demand patterns

### 📋 Detailed Report

The dashboard also includes an interactive detailed table with:

- Search
- Sorting
- Pagination
- Filtered records
- Order-level details

## 🤖 Using AI in the Development Process

One of the interesting parts of this project was using **AI as a development tool**.

Instead of manually implementing every dashboard component from scratch, I used AI to assist with:

- HTML dashboard development
- Interactive charts
- UI components
- Filters and interactions
- Data presentation
- Debugging and improvements

This significantly reduced development time and effort and allowed me to focus more on the **data, business logic, analysis, and insights**.

> AI didn't replace the analytical work — it helped turn the ideas and requirements into a working product much faster.
